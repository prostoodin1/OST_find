# История OST Finder

Личный репозиторий проекта: [OST_find](https://github.com/prostoodin1/OST_find).

| Версия | Интерфейс | Основное изменение |
| --- | --- | --- |
| [0.5.0 Wireframe](https://github.com/prostoodin1/OST_find/releases/tag/v0.5.0) | GUI + CLI | каркасный паук по видеореференсу, лапы привязаны к DOM, захват ссылок и текста, подсветка и поднимающиеся фрагменты |
| [0.4.0 Spider](https://github.com/prostoodin1/OST_find/releases/tag/v0.4.0) | GUI + отдельный CLI | приватный мини-браузер, сбор DOM-ссылок и метаданных, анимированный паук |
| [0.3.0](https://github.com/prostoodin1/OST_find/releases/tag/v0.3.0) | терминал | постоянная сессия, прямой EXE, GitLab, urlscan, расширенный публичный OSINT |
| [0.2.0](https://github.com/prostoodin1/OST_find/releases/tag/v0.2.0) | исторический GUI | повторный поиск, подсказки, исправление редиректов и расширенный веб-поиск |
| [0.1.1](https://github.com/prostoodin1/OST_find/releases/tag/v0.1.1) | терминал, portable ZIP | исправленная упаковка после антивирусного срабатывания первой сборки |
| [0.1.0](https://github.com/prostoodin1/OST_find/releases/tag/v0.1.0) | терминал | первая экспериментальная версия; устарела |

28.10.2026 оригинальные файлы версий 0.1.0, 0.1.1, 0.2.0 и 0.3.0 скопированы из приватного Ideas_projects с проверкой размера и SHA-256. Старые релизы Ideas сохранены. Метки `v0.2.0` и `v0.3.0` указывают на соответствующие коммиты; `v0.1.1` восстановлена из оригинального архива исходников. В релизе 0.1.0 дополнительно оставлен `SHA256SUMS-original.txt` от первоначальной самостоятельной публикации.

Старые файлы не пересобирались и не переименовывались. Исторические проверки относятся к датам исходных публикаций, а не к повторному тестированию всех старых версий сегодня.
