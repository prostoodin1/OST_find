# OST_find 0.1.1

Updated Ideas preview release.

The portable Windows folder runs without a separate Python installation. It searches public web, developer, discussion, domain, and profile sources, then writes inspectable JSON and Markdown reports.

Version 0.1.1 replaces the unsigned self-extracting executable with a smaller dependency set, Windows product metadata, and a normal portable folder inside a ZIP to reduce false-positive antivirus detections.

No API keys are required. The tool does not bypass authentication or access private databases.
