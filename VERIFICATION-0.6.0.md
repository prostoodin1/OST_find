## Обновление

- Настоящий `update_helper.ps1` выполнен в отдельных временных Windows-каталогах со специально собранными тестовыми EXE: успешная установка/перезапуск, откат при отказе нового EXE на healthcheck и отказ до замены при несовпадении SHA-256. Все три сценария прошли.
- Проверены пути с пробелом, апострофом и `&`; `_internal` заменяется целиком, пользовательский `reports/keep.txt` сохраняется, прежняя версия остаётся в backup.
- Автотест загрузки: несовпадение контрольной суммы не меняет установленный EXE; успешная подготовка создаёт manifest и копирует helper.
- Живой публичный latest API проверен без авторизации: сравнение версий, выбор CLI asset и отказ от понижения версии.
- Последующая проверка загрузки опубликованного 0.6.0 и установки на временную копию фиксируется отдельно в GitHub release notes; она возможна только после публикации.

## Сборки и ограничения

- PyInstaller 6.22.3, Python 3.13.0, PySide6 6.10.3; GUI отдельный EXE и полный portable ZIP, CLI отдельный EXE и portable ZIP.
- Microsoft Defender CustomScan завершился для финальных GUI/CLI EXE и обеих portable-папок; соответствующих обнаружений не найдено. Другие антивирусы, SmartScreen и чистая вторая Windows-машина не проверялись.
- Brave с живым платным/пользовательским ключом и реальные LLM-модели не вызывались. Проверены схема/ограничения и обработка ответов на контролируемых тестах. LLM по умолчанию отключён.
- Балл свидетельств и автоматические предупреждения не доказывают истинность, независимость источников или личность человека. Персональные данные могут присутствовать в публичных страницах: локальное сохранение отключается пользователем.
- SHA-256 сверяется с HTTPS-метаданными GitHub; подписи разработчика пока нет. Текущая 0.5.0 требует одного ручного перехода на 0.6.0.

QA-данные, видео пользователя, скриншоты тестов, временные EXE/профили/отчёты не входят в git и release source archive.
